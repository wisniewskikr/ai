Wybór stacku technologicznego pod pracę z AI to nie kwestia mody, ale zapewnienia agentowi **czytelnej mapy drogowej**. Agent działa najlepiej, gdy nie musi zgadywać Twoich intencji.

### 4 Filary Stacku Przyjaznego Agentowi
Dobry stack dostarcza agentowi jasnych sygnałów, co minimalizuje błędy i konieczność poprawek.

| Cecha | Dlaczego jest kluczowa? | Analogia |
| :--- | :--- | :--- |
| **Typowanie** | Definiuje jasne kontrakty danych. | **Mapa z numerami domów** – agent nie szuka po omacku. |
| **Konwencje** | Ustalony porządek plików i logiki. | **Standardowa kuchnia** – zawsze wiesz, gdzie są sztućce. |
| **Popularność** | Więcej danych treningowych dla modelu. | **Doświadczony przewodnik**, który zna miasto na pamięć. |
| **Dokumentacja** | Agent korzysta z faktów, a nie zmyśla API. | **Aktualna instrukcja**, która zapobiega improwizacji. |

### Rekomendowany "Złoty Stack"
To ścieżka najlepiej wspierana w kursie, dająca największy spokój na start.

*   **Astro 6**: Zarządza całością (routing, API). Działa jak solidny fundament domu.
*   **React 19**: Tworzy interaktywne "wyspy" tam, gdzie są potrzebne.
*   **TypeScript**: Najważniejszy sygnał dla agenta – eliminuje zgadywanie kształtu danych.
*   **Tailwind CSS 4**: Stylizacja bezpośrednio w HTML. Agent widzi strukturę i wygląd w jednym miejscu.
*   **Supabase**: Gotowe usługi backendowe (baza, auth) z gotowym SDK.
*   **Cloudflare**: Szybka droga z Twojego komputera do sieci.

### Twój własny stack?
Możesz go użyć, jeśli czujesz się w nim pewnie i spełnia on kryteria "agent-friendly".

**Zostań przy swoim, jeśli:**
*   Używasz typów (TS, Java, C#, Python z type hints).
*   Startujesz z dojrzałego szablonu, a nie z pustego folderu.
*   Struktura projektu jest oparta na znanych konwencjach.
*   Potrafisz szybko wyłapać błędy agenta w tym ekosystemie.

---

### Minimum wiedzy na start
Nie musisz być ekspertem od powyższych technologii przed rozpoczęciem pracy z agentem.

**Co warto wiedzieć:**
*   **Typy**: Rozumieć, jak pomagają agentowi (np. TypeScript).
*   **API**: Ogólne pojęcie o tym, jak działają zapytania i odpowiedzi (JSON, HTTP).
*   **Narzędzia**: Umiejętność zainstalowania zależności i uruchomienia komendy `dev`.

**Czego NIE musisz umieć:**
*   Perfekcyjnej składni frameworków (napiszesz ją z agentem).
*   Konfiguracji serwerów i chmury.
*   Zaawansowanych wzorców architektonicznych.

**Zasada decyzji:** Jeśli nie masz silnej preferencji, wybierz stack kursowy – to najbezpieczniejsza i najlepiej opisana droga.
