# CLAUDFLARE

Najprościej:

AWS to centrum danych i cała chmura obliczeniowa.
Cloudflare to warstwa ochrony i przyspieszania internetu, która zwykle stoi przed AWS.

Wyobraź sobie restaurację:

AWS = kuchnia, magazyn, lodówki, pracownicy.
Cloudflare = ochrona przy wejściu, recepcja i system kierujący gości do właściwego stolika.

One nie są bezpośrednimi konkurentami – bardzo często używa się ich razem.

Czym jest Cloudflare?

To firma, która dostarcza usługi związane z:

CDN – przyspieszanie stron internetowych (serwowanie treści z serwerów blisko użytkownika)
DNS – tłumaczenie moja-strona.pl → adres IP
DDoS protection – ochrona przed atakami przeciążającymi serwer
WAF (Web Application Firewall) – firewall dla aplikacji webowych
SSL/TLS – certyfikaty HTTPS
Edge computing (Workers) – uruchamianie małych fragmentów kodu blisko użytkownika.

Cloudflare działa jako pośrednik między użytkownikiem a twoją infrastrukturą. Użytkownik nie łączy się bezpośrednio z twoim serwerem.
