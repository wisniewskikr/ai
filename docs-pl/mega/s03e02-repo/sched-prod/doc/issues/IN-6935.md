## Intent
Next to the CSV download, add a JSON download with the same data.

## Acceptance
- Given an account's bookings, when the JSON is downloaded, then it holds every field the CSV holds, for every booking (PRD-3).
- Given any time in the JSON, when read, then it says its zone (ADR-0001).
- Given the CSV download, when the JSON ships, then the CSV file is unchanged, not one column moved.
- A test compares the CSV and JSON for the same account.

## Boundaries
- Must not change the CSV export.
- Must not leave out any field the CSV carries.

Allowed by AUT-1 (new fields that add to what is there and take nothing away).
