## Intent
Add a high-contrast mode to the booking page, built as a new colour token set from the existing palette (DES-2). A customer with low vision needs it.

## Acceptance
- Given the booking page, when high-contrast mode is on, then every colour comes from the new token set.
- Given the new token set, when checked, then every value comes from the palette already in the tokens file, and no new colour is picked.
- Given high-contrast mode is off, when the page loads, then it does not look any different from before.
- Given a component, when searched, then it holds no raw colour values (DES-2).

## Boundaries
- Must not add colour values to components.
- Must not start before SCHED-4412 ships, since raw colours would not follow the token set.

Allowed by AUT-1 (a new colour scheme built as a token set from the existing palette — DES-2).
