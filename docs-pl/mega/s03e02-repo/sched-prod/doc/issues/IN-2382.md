## Intent
The CSV export quotes every field that holds a comma, a quote or a line break (RFC 4180), so a client name with a comma stays in its own column.

## Acceptance
- Given a client named "Smith, Jones & Co", when the CSV is exported, then the name sits in one quoted field and every later column stays in place.
- Given a name with a double quote, when exported, then the quote is doubled inside a quoted field.
- Given a row with no special characters, when exported, then its text does not change.
- Given any export, when compared to before, then no column is added, removed or renamed (PRD-3).
- A test covers commas, quotes and line breaks.

## Boundaries
- Must not change column names, order or the date format (IN-5011).

Allowed by AUT-1 (bug fixes inside the specs, with a test — PRD-3).
