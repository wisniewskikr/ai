## Intent
The booking confirmation page shows the booking's time with its time zone, so people abroad know which zone it is in (PRD-2, ADR-0001).

## Acceptance
- Given a booking made from another zone than the account's, when the confirmation page shows, then the time carries its zone name (e.g. "10:00 CET").
- Given the viewer's zone, when the time is shown, then it is converted to that zone and labelled with it (PRD-2).
- Given the stored booking, when the page changes, then its stored UTC time does not change.
- A test covers a viewer in another zone.

## Boundaries
- Must not change stored times or emails.

Allowed by AUT-1 (bug fixes inside the specs, with a test — ADR-0001: a time without a zone is a bug).
