## Intent
Staff can search the bookings list by booking reference as well as by name.

## Acceptance
- Given a booking with reference ABCDE12345, when staff search for it, then that booking is found.
- Given a search for a name, when it runs, then it still finds names, with or without accents (SCHED-4442).
- Given a reference that does not exist, when searched, then no other booking is shown as a match.
- A test covers search by reference and by name.

## Boundaries
- Must not change the references themselves (see IN-8446).
- Must not change name search.

Allowed by AUT-1 (new filters that add to what is there and take nothing away).
