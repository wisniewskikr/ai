## Question
Support asks to show the dates in the CSV export as dd/mm for EU accounts (IN-6295, "a one-line change"). A client in Auckland says their payroll import reads the export as mm/dd today and asks us not to flip it (IN-5011). Do we change the date format of the existing export columns?

## Options
1. Flip the existing date columns to dd/mm for EU accounts.
2. Keep the existing columns as they are and add new, unambiguous date columns (ISO 8601 with offset, see SCHED-4446) that EU accounts can use.
3. Make the format a per-account export setting, defaulting to today's format.

## Recommendation
Option 2.

## Why
Because a client told us they rely on today's format (IN-5011), which makes this a human call (AUT-2), and an export never loses what it had (PRD-3). Adding columns is allowed to an agent (AUT-1) and ADR-0001 asks exports to say which zone a time is in.
