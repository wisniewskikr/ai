## Intent
The "Add to calendar" link in the booking confirmation email opens a calendar event for the booking. Split from merged ticket IN-5408 (2 reports, two problems).

## Acceptance
- Given a confirmation email, when "Add to calendar" is clicked, then a calendar event file for the booking downloads, with its start and end and their zone (ADR-0001).
- Given the link of one booking, when opened, then it does not show another booking.
- Given the event, when it is added, then sched-prod does not read anything back from that calendar (ADR-0002).
- A test opens the link.

## Boundaries
- Must not change calendar sync.
