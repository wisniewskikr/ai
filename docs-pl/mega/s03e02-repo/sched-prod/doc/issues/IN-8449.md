## Intent
Add a column to the CSV export that says where each booking came from: link, widget or API (the Channel primitive, specs/product.md).

## Acceptance
- Given bookings from the link, the widget and the API, when exported, then the new column reads link, widget and api for them.
- Given any export, when compared to before, then every existing column keeps its name, order and format, and none is removed (PRD-3).
- Given the new column, when added, then it is placed after the existing columns, not between them.

## Boundaries
- Must not change or reorder existing columns.

Allowed by AUT-1 (new columns that add to what is there and take nothing away).
