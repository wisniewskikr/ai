## Intent
The date picker on the booking page works with the keyboard alone: focus, move between days, pick a day, close.

## Acceptance
- Given focus on the date picker, when the arrow keys are pressed, then focus moves between days.
- Given a day in focus, when Enter or Space is pressed, then that day is picked and its times load.
- Given an open picker, when Escape is pressed, then it closes and focus returns to the field, not to the top of the page.
- A test drives the picker by keyboard only.

## Boundaries
- Must not change how the picker looks to mouse users.
- Must not use colours or sizes outside the tokens (DES-1, DES-2).

Allowed by AUT-1 (bug fixes inside the specs, with a test).
