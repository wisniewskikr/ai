# Email Bot z nadzorem czlowieka

> Bot jak sekretarka — pisze, Ty decydujesz czy wyslac.

---

## Co robi?

Pytasz bota o temat, odbiorcę i ogólny pomysł. Bot pisze formalnego maila. Ty go zatwierdzasz albo odrzucasz.

---

## Zalozenia

| # | Co | Szczegoly |
|---|-----|-----------|
| 1 | Typ maila | Sluzbowy, formalny |
| 2 | Jezyk | Zgodny z koncepcja uzytkownika |
| 3 | Stopka AI | Zawsze dodana: "Generated by AI" |
| 4 | Podpis | Zawsze: "Chris Cherry, Senior Java Developer" |
| 5 | Wyjscie | `/exit` dziala w kazdym kroku |

---

## Jak dziala? (krok po kroku)

```
[1]  Podaj temat maila
[2]  Podaj odbiorce
[3]  Opisz ogolna koncepcje
[4]  Bot generuje maila
[5]  Wybierasz co dalej:
       A — Approve  → zapisz do workspace/emails/
       R — Recreate → wygeneruj jeszcze raz
       C — Cancel   → porzuc
[6]  Nowy mail? [T/N]
```

---

## Stack

| Element | Technologia |
|---------|-------------|
| Jezyk | TypeScript (Node.js) |
| API | OpenRouter |
| Konsola | Node.js `readline` |
| Zapis maili | `fs` → `workspace/emails/` |
| Konfiguracja | `.env` (OPENROUTER_API_KEY) |
