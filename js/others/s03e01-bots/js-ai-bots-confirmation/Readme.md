# Email Bot — Human in the Loop

> Like a secretary — it writes, you decide whether to send.

---

## What does it do?

You describe an email. The bot writes it. You approve it (or toss it).

No email leaves without your explicit `A` (Approve).

---

## Requirements

| What | Version |
|------|---------|
| Node.js | 18+ |
| npm | 8+ |
| OpenRouter API key | [openrouter.ai](https://openrouter.ai) |

---

## Installation

```bash
npm install
```

Copy `.env.example` to `.env` and fill in your API key:

```bash
cp .env.example .env
```

```
OPENROUTER_API_KEY=your-key-here
```

---

## Running

```bash
npm start
```

### Flow

```
[1]  Enter email topic
[2]  Enter recipient
[3]  Describe the concept
[4]  Bot generates the email
[5]  You choose:
       A — Approve  → saved to workspace/emails/
       R — Recreate → generate again (same input)
       C — Cancel   → discard
[6]  New email? [Y/N]
```

Type `/exit` at any prompt to quit immediately.

---

## Configuration

Edit `config.json` to change the model, signature, or output folder:

```json
{
  "model": "openai/gpt-4o-mini",
  "signature": "Chris Cherry, Senior Java Developer",
  "aiFooter": "--- Generated by AI ---",
  "emailsDir": "workspace/emails"
}
```
